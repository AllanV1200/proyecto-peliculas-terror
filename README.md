## 🎥 📖 Descripción

**TerrorPelis** es un proyecto web desarrollado como parte del
**Proyecto Final de HTML5, CSS3 y JavaScript**.

El proyecto consiste en una página web dedicada al género
cinematográfico de **terror**, donde los usuarios podrán encontrar
información relacionada con películas, personajes, categorías y
diferentes elementos característicos del cine de terror.

La página está diseñada para ofrecer una experiencia visual,
interactiva y entretenida, utilizando imágenes, contenido multimedia
y diferentes funciones desarrolladas mediante JavaScript.

El proyecto combina una temática oscura relacionada con el terror
con elementos visuales llamativos para crear una interfaz atractiva
para los usuarios.

---

## 🧟 🎯 Objetivo del proyecto

Desarrollar una página web interactiva sobre películas de terror,
aplicando los conocimientos adquiridos en **HTML5, CSS3 y JavaScript**.

El objetivo es crear un sitio organizado, funcional y visualmente
atractivo que permita presentar información sobre el género de terror
y mejorar la experiencia del usuario mediante elementos interactivos
y multimedia.
